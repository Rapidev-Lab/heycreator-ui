🎬 Proposed: TikTok-Style Content Discovery

Transform discovery from static profile cards into an engaging, content-first experience. Brands discover creators through their best content, not just their stats.

✨ Why Content-First Discovery?

Currently, brands search and get a grid of profile cards showing names, follower counts, and handles. This is functional but doesn't help brands evaluate content quality — the #1 factor in creator selection. A TikTok-style feed lets brands:

  • See content first — Video thumbnails, reels, posts as the primary display
  • Evaluate style & quality — Before viewing any stats
  • Discover through engagement — Swipe, like, save, shortlist in a natural flow
  • Reduce decision fatigue — One creator at a time vs. overwhelming grid
  • Mobile-native experience — Feels natural on phones and tablets

Content Feed → Swipe/Engage → Creator Profile → Campaign Invite

💡 Best Practice Improvements

Code quality and architecture recommendations.

Consolidate Auth Contexts
Two auth context paths (/lib/firebase/auth-context.tsx and /lib/context/AuthContext.tsx) create confusion. Consolidate to one. Remove deprecated mock context.
Server-Side Auth Middleware
Replace x-user-id header with Firebase ID token validation. Add Next.js middleware for protected routes.
Form Validation Library
Adopt Zod for schema validation across all forms. Replace inconsistent inline validation in campaign creation steps.
Semantic HTML
Replace <div> wrappers with <main>, <nav>, <header>, <article> landmarks. Add skip-to-content link.
Consistent Loading States
Every data-fetching page should use Skeleton components. Add loading.tsx files in app directories for automatic Next.js suspense boundaries.
Remove Dead Code
Delete RoleCard copy.tsx, page_old.tsx files, mock-auth-context.tsx. Consolidate duplicate DiscoveryHeader and UserProfileHeader.
